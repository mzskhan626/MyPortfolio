## 🛠️ Run Locally

To run this portfolio locally:

```bash
git clone https://github.com/mzskhan626/MyPortfolio.git
cd MyPortfolio
open index.html in your browser
```

If hosting your own version, make sure to update:

- Email endpoint in the `form` action
- Resume link path and logo image
- Meta tags for SEO/social preview (in `<head>`)
